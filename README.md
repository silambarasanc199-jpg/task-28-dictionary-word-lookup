# 📖 Dictionary & Word Lookup App

A futuristic and responsive Dictionary & Word Lookup Web Application built as part of the **Veda Technology Web Development Task 28**.

The application allows users to search for English words and view their definitions, phonetics, parts of speech, examples, multiple meanings, and pronunciation audio when available.

## 📌 Project Overview

The Dictionary & Word Lookup App provides a simple and professional interface for searching English words using a public dictionary API.

Users can enter a word, search for its meaning, and view structured dictionary information dynamically.

The project focuses on:

- API integration
- Fetch API
- Asynchronous JavaScript
- Error handling
- Responsive web design
- Dynamic DOM manipulation
- User-friendly UI/UX

---

## 🎯 Task Objective

The objective of this task is to build a dictionary application that can:

- Search for English words
- Display word definitions
- Display phonetic information
- Show parts of speech
- Display example sentences
- Support multiple meanings
- Provide pronunciation audio when available
- Handle invalid or unavailable words
- Work across desktop and mobile devices

---

## ✨ Features

### 🔎 Word Search

Users can enter an English word and retrieve dictionary information.

### 📚 Multiple Definitions

The application displays all available meanings returned by the dictionary API.

### 🏷️ Parts of Speech

Definitions are grouped according to parts of speech such as:

- Noun
- Verb
- Adjective
- Adverb
- Pronoun
- Preposition

### 🔤 Phonetics

The application displays phonetic information whenever it is available.

### 🔊 Pronunciation

If pronunciation audio is provided by the API, users can play the pronunciation directly from the application.

### 💬 Example Sentences

Example usage is displayed when available.

### ⚠️ Error Handling

The application provides clear messages when:

- A word does not exist
- The API request fails
- Invalid input is entered
- No dictionary data is available

### 📱 Responsive Design

The interface is designed to work on:

- 📱 Mobile
- 📲 Tablet
- 💻 Desktop

### 🕘 Recent Searches

Recently searched words can be stored locally in the browser for easier access.

### ⌨️ Keyboard Support

The application provides convenient keyboard interactions for searching and navigation.
